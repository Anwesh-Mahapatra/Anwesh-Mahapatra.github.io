# About

I'm **Anwesh Mahapatra**, a detection engineer with about four years in security operations.

Most of my work is in **Google SecOps (Chronicle)**:

- Writing and tuning **YARA-L** detection rules
- Building and fixing **UDM parsers** and parser extensions
- Onboarding log sources (Entra ID, Defender XDR, firewalls, Windows and Linux)
- Pipelines with **Bindplane** and **Cribl**
- **SOAR** actions and playbooks

I'm working towards **cloud detection and response** and **security data engineering**.

**Certifications:** Google Cloud Professional Cloud Security Engineer, Cribl Certified User.
